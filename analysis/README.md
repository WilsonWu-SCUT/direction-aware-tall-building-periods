# Analysis workflows

The repository has two independent, database-driven analysis paths:

- [Period prediction](period_prediction/README.md): directional power-law
  regression, coefficient constraints, tables, and predicted periods.
- [Azimuth prediction](azimuth_prediction/README.md): plan-section properties,
  principal directions, equivalent rectangles, regularity, and figures.

Both guides list their input database, command-line entry points, generated
outputs, and verification commands.
